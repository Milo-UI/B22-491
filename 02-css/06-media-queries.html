CSS 05 - Media queries

Design responsive

Il design responsive è un approccio alla progettazione e allo sviluppo di siti che mira a garantire un'esperienza utente ottimale a prescindere dal dispositivo (desktop, tablet, smartphone) che viene usato.

Per creare un design responsive, gli elementi della pagina devono ridimensionarsi e riorganizzarsi in base alla larghezza dello schermo.
Questo permette di avere un solo sito da gestire per tutte le piattaforme, riducendo il bisogno versioni separate per ogni tipo di dispositivo.

Mobile first

Ormai è fondamentale utilizzare un approccio mobile first nella progettazione di un sito, ovvero un approccio che prioritizza la creazioe di esperienze ottimali per dispositivi mobili prima di adattarle a schermi più grandi, come desktop e tablet.

Si inizia a progettare il sito per dispositivi di dimensioni più piccole, assicurandosi che tutte le funzionalità siano accessibili e utilizzabili da smartphone.
Per aggiungere funzionalità e migliormaenti per schermi più grandi, utilizziamo le media queries.

Media queries

Le media queries sono una funzionalità CSS che consente di applicare stili specifici a un documento HTML in base alle caratteristiche del dispositivo su cui viene visualizzato, come la larghezza dello schermo, l'orientamento e la risoluzione. Sono fondamentali per il design responsive e per garantire che un sito web si adatti a tutte le dimensioni di schermo possibili.
